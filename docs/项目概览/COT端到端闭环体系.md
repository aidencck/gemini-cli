# COT端到端闭环体系（微调 → 使用 → 输出处理）

本文件从技术专家视角，系统化、分层次、结构化梳理项目中“思维链（Chain-of-Thought，COT）”的端到端闭环：从微调与数据到使用与推理，再到输出处理与治理。强调质量保障与可运营性，不涉及具体代码实现。

## 核心结论（Executive Summary）
- 闭环视角：数据/微调 → 运行时使用 → 输出处理 → 观测与治理 → 迭代优化。
- 项目落地：本项目在“使用/输出处理”阶段提供完善管线（意图识别、COT识别与隔离、工具调度、结构化装配、历史维护与压缩）；“微调”阶段作为外部能力接入（不在本仓库实现）。
- 质量策略：以精选历史与统一输出契约为基础，结合判定门控、错误兜底、测试与遥测，形成可度量与可迭代的稳定体系。

## 分层架构与责任边界
- 数据与微调层（外部能力）
  - 目标：通过带标注的“思维链”数据进行监督微调/偏好优化，使模型更稳定地产生可控COT（含Zero-shot/Few-shot CoT、自一致性等策略）。
  - 本项目关系：不直接负责训练；通过提示工程与“思维链支持开关”（例如 `isThinkingSupported(model)`）适配模型能力。
- 使用与推理层（Runtime COT）
  - 意图识别：“下一说话人判定”采用精选历史 + 统一JSON返回；同时对函数响应与空模型消息进行本地兜底。
  - COT识别与隔离：检测首段 `thought: true` 的模型输出，将内部推理与可展示内容分离，避免污染用户显示与工具输入。
  - 工具协同：模型声明 `functionCall` → 调度执行 → 结果转译为 `functionResponse` 并写回历史。
  - 历史与压缩：综合历史与精选历史双轨维护；在令牌阈值处触发总结压缩并重建上下文。
- 输出处理层（Assembly & Delivery）
  - 结构化装配：将文本与函数调用统一为“文本 + JSON”或单独文本/JSON，适配CLI/文档/API消费。
  - 流式/非流式一致性：在非流式完成或流式最后片段处统一触发解析、过滤与历史写入，保证幂等与一致。
- 观测与治理层（Observability & Governance）
  - 指标：判定命中率、工具成功率、输出契约稳定性、时延与成本、压缩触发率。
  - 安全与隐私：最小化披露、参数与返回值脱敏、权限与敏感操作审计；错误分级与告警。

## 端到端闭环详解
- 微调阶段（外部）
  - 数据采集：任务与领域覆盖、COT标注规范、质量抽样与互评。
  - 策略与方法：监督微调（SFT）、自一致性（Self-Consistency）、偏好优化（DPO/RLHF）、合成COT与蒸馏。
  - 质量度量：推理稳定性、可解释性、任务成功率、长度与成本；黑盒/白盒评估与安全审查。
- 使用阶段（本项目）
  - 输入装配：精选历史作为判定上下文；综合历史用于最后消息结构检查与兜底。
  - 判定门控：
    - 下一说话人：精选历史 + 判定提示 → 返回 `{ next_speaker, reasoning }`（JSON模式）。
    - 工具意图：从响应 `parts` 中抽取函数调用；进入调度与统一转译。
    - COT识别：首段 `thought: true` → 隔离处理。
  - 流程一致性：非流式一次性解析；流式在最终片段统一解析与写入。
- 输出处理阶段（本项目）
  - 结构化输出：文本与工具调用统一装配；MCP工具响应做内容提取与JSON化展示。
  - 历史写入与回放安全：空模型消息兜底、函数响应检测避免非法结构回传；压缩与重置保障上下文持续可用。

## 质量保障与可运营性（Quality & Ops）
- 契约稳定性：统一的结构化输出格式（文本/JSON）与历史写入规则（精选/综合）。
- 测试策略：
  - 单测：意图门控、函数响应转译、结构化装配、COT识别分支。
  - 集成：多回合与工具闭环；流式/非流式一致性验证；压缩触发与上下文重建。
  - 契约/快照：固定输出格式与工具响应结构，避免对消费端造成回归。
- 遥测与指标：
  - 判定相关：下一说话人决策命中率、兜底触发率、判定时延。
  - 工具相关：成功率/失败率/取消率、平均执行时长、重试次数。
  - 输出相关：结构化装配错误率、COT过滤正确率、流式落盘一致性。
  - 成本相关：令牌用量、压缩频率、调用次数与费用估算。
- 运行策略：
  - 策略开关：仅本地/本地优先+模型兜底/模型优先；按场景切换。
  - 安全策略：参数与返回值脱敏、敏感工具确认机制、审计日志与告警。

## 路线图与扩展建议
- 微调协同：引入外部训练成果（带COT的SFT/自一致性策略），建立模型能力评估与灰度上线。
- RAG集成：将检索结果纳入精选历史，提升复杂任务中的推理质量与可用性。
- 策略引擎：可配置的意图与COT处理策略（规则/概率/成本约束），支持AB实验。
- 可视化与治理：
  - 时序/状态图：门控、工具、装配与历史的可视化。
  - 策略控制台：判定阈值、提示模板、压缩策略的在线配置。
- 企业级能力：SLA与告警、细粒度权限、数据主权与合规部署。

## 时序概要（文本版）
- 非流式：用户输入 → 模型生成 → 抽取函数调用/文本 → 工具调度与结果转译 → COT过滤/结构化装配 → 历史记录（精选/综合） → 下一说话人判定 → 续写或等待。
- 流式：用户输入 → 模型流式生成（增量片段） → 最末片段合并 → 同步抽取/过滤/装配 → 历史记录 → 下一说话人判定。
