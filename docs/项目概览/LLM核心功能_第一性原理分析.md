# LLM 核心功能的第一性原理分析（体系化/结构化/分层次）

## 文档目标与适用范围
- 用第一性原理拆解“大语言模型（LLM）”的核心功能与工程约束，避免经验主义与术语混乱。
- 提供分层架构、关键能力、约束与权衡、评价指标、风险与治理建议，并映射到本项目的实现位置。
- 面向架构师与工程团队，用于设计决策、能力规划、质量门禁与演进路线图。

## 第一性原理（Minimal Axioms）
- 概率生成模型：LLM 本质上近似学习条件分布 `p(next_token | context)`，以最小化训练目标（如交叉熵）。
- 上下文即程序：推理时，输入上下文（系统提示/历史/检索/工具返回）决定输出分布，解码策略决定具体输出。
- 能力涌现受规模驱动：模型及数据规模、训练方法与对齐（SFT/DPO/RLHF）共同决定“指令遵循、逐步推理（CoT）、函数调用”等能力的稳定性与泛化。
- 成本与质量的基本约束：有限的上下文窗口、延迟与费用、错误与幻觉风险；需要在给定约束下优化“精度-时延-成本”三角。

## 核心功能分层（Capabilities by Layers）
- 表征层（Representation）
  - Token/Embedding：字节对编码/词片段；语义向量；位置与结构编码。
  - 设计要点：分块/摘要/压缩；跨文档/多文件的结构对齐。
- 生成与解码层（Generation & Decoding）
  - 策略：Greedy/Beam/Sampling（温度、top-p）、停止符、长度与格式约束。
  - 设计要点：稳定性与多样性权衡、输出契约、错误兜底与重试。
- 指令遵循层（Instruction Following）
  - 能力：遵循明确指令与风格；结构化输出；角色与边界控制。
  - 设计要点：系统提示分层（角色/流程/安全/工具）、少样本示范与风格一致性。
- 推理与思维链层（Reasoning & CoT）
  - 能力：多步推理、计划-执行、对比/自一致性采样。
  - 设计要点：COT 隔离（thought:true）、结构化分段（思考→调用→结论）、覆盖与一致性评估。
- 工具调用层（Function/Tool Use）
  - 能力：识别函数意图、生成参数、触发本地执行、合并结果。
  - 设计要点：Tool Registry/参数 Schema/权限与审批、结果结构化、异常回退与审计。
- 记忆与上下文层（Memory & Context）
  - 能力：历史维护、精选与压缩、检索增强（RAG）、外部知识注入。
  - 设计要点：令牌预算、摘要保真度、快照与可追溯性、跨会话/跨设备持久化。
- 交互与编排层（Interaction & Orchestration）
  - 能力：输入解析→意图识别→规划→执行→反馈闭环；流式与非流式一致性。
  - 设计要点：状态机/时序图、超时与重试、取消与确认、人机协同与可视化。
- 观测与治理层（Observability & Governance）
  - 能力：遥测、日志、指标与告警；隐私与合规；版本/策略管理。
  - 设计要点：质量门禁（指标阈值）、审计链、策略外置与灰度。

## 约束与权衡（Constraints & Trade-offs）
- 上下文窗口：有限的 token 上限，需做“摘要/压缩/检索”与“信息保真”的权衡。
- 延迟与费用：解码步长与温度/采样次数；工具调用/网络 IO；并发与节流。
- 准确性与稳定性：追求正确与可复现；对抗幻觉与不确定性；自一致性提升稳健性但增加成本。
- 安全与隐私：最小披露、权限控制、脱敏与审计；工具执行的沙箱与白名单。

## 评价指标（Metrics）
- 任务正确性：`pass@1`、测试通过率、结构契约合规率、工具成功率。
- 推理质量：COT 覆盖率与一致性、决策可解释性、错误率与重试率。
- 性能与成本：TTFB、完整响应时间、tokens_in/out、压缩节省比、并发度与资源占用。
- 稳定性与可靠性：成功率、降级率、回退率、异常分类与告警命中率。
- 安全与合规：敏感信息命中率（越低越好）、审批覆盖率、审计完整性。

## 失效模式与缓解（Failure Modes & Mitigations）
- 幻觉与事实错误：引用与来源标注、RAG 校准、人工抽检与自一致性投票。
- 结构不合法：输出契约（JSON/Markdown）与验证器；失败兜底与重试。
- 工具调用失败：参数校验、权限与审批、回退与提示；结果超时与取消。
- 上下文污染：COT 隔离、精选历史与摘要快照；敏感内容过滤与脱敏。

## 第一性原理下的工程策略（Actionable Strategy）
- 输入构造与上下文工程
  - 优先级：需求/接口/约束→关键代码/文档→历史摘要→检索上下文。
  - 策略：分层提示、格式契约、少样本示范；对复杂任务采用“计划-执行”显式结构。
- 推理与工具耦合
  - 使用 `functionCall`→`ToolRegistry`→`executeToolCall` 的受控链路；关键工具走审批、写操作预览与确认。
  - 输出结构化装配，统一“文本 + 工具响应/引用”复合格式，便于验证与复用。
- 历史与压缩
  - 令牌阈值触发摘要压缩；保留摘要快照与审计信息；在非交互与流式路径保持一致的解析/写入逻辑。
- 评估与门禁
  - 建立契约快照测试与评估集；设置阈值（TTFB/通过率/结构合规性）；失败即重试或降级。
- 安全与治理
  - 最小权限与脱敏；审计与版本/策略管理；异常分级与告警；策略外置与灰度。

## 示例：结构化输出契约（建议）
- 对话摘要压缩（现有）：`ChatCompressionInfo { originalTokenCount; newTokenCount; }`。
- 建议引入统一响应结构（示意）：
```json
{
  "kind": "llm_output",
  "content": [{"type":"text","text":"..."}],
  "tools": [{"name":"grep","args":{"query":"..."},"result":{"count":42},"ok":true}],
  "citations": [{"source":"/path/file.ts","loc":"120-140"}],
  "metrics": {"tokens_in": 2048, "tokens_out": 256, "latency_ms": 900},
  "audit": {"created_at": "2025-11-06T12:00:00Z", "parameters": {"temperature":0, "topP":1}},
  "confidence": 0.78
}
```

## 路线图（Roadmap）
- P0：格式契约与验证器、提示模板外置、压缩阈值配置化、评估集与快照测试。
- P1：RAG 接入与知识增强、策略引擎（任务/成本/概率门控）、可视化控制台（时序/状态/热图）。
- P2：企业级治理（SLA、细粒度权限、合规）、持久化会话与恢复、工具生态与插件化。
