# 架构设计Prompt模板总览

## 使用指南

### 选择模板
根据项目阶段和需求选择合适的模板：

1. **项目初期**: 使用技术方案设计模板
2. **架构设计**: 使用系统架构分析模板
3. **设计评审**: 使用系统设计评审模板
4. **代码重构**: 使用代码架构重构模板
5. **微服务设计**: 使用微服务架构设计模板

### 模板组合使用
可以组合使用多个模板：

- **新项目**: 技术方案设计 → 系统架构分析 → 系统设计评审
- **重构项目**: 系统架构分析 → 代码架构重构 → 系统设计评审
- **微服务迁移**: 系统架构分析 → 微服务架构设计 → 系统设计评审

### 自定义调整
根据具体项目需求调整模板：

1. **简化模板**: 删除不相关的维度
2. **扩展模板**: 添加项目特定的维度
3. **调整优先级**: 根据项目重点调整分析维度
4. **定制输出**: 根据团队需求定制输出格式
